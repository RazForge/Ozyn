Ozayn API Documentation

REST API for the Ozayn Personal AI Digital Twin

Authentication

All endpoints require a valid session ID in the X-Session-ID header.

POST /api/v1/auth/register

Register a new user

POST /api/v1/auth/login

Login and get session ID

POST /api/v1/auth/logout

Logout and destroy session

Chat

POST /api/v1/chat/send

Send a message and get AI response

GET /api/v1/chat/history/{id}

Get conversation history

GET /api/v1/chat/list

List all conversations

Projects

GET /api/v1/projects/list

List all projects

POST /api/v1/projects/create

Create a new project

Tasks

GET /api/v1/tasks/list

List all tasks

POST /api/v1/tasks/create

Create a new task

ARWE Systems

GET /api/v1/arwe/status

Get all ARWE system statuses

GET /api/v1/arwe/briefing

Get daily ARWE briefing
